# Primeyield Ventures One-Page

Create a premium, modern single-page static website for Primeyield Ventures, a software development company. Everything must be on ONE page with smooth scrolling; do not create separate pages or routes.

Structure exactly:
Header → Home → About → Services → Product Showcase + Contact → Footer

Create a sticky header with the golden Primeyield Ventures logo, navigation: Home, About, Services, Products, Contact, plus a Dark/Light theme toggle. Clicking navigation items must smoothly scroll to the respective section on the same page.

Create both Dark and Light modes with the same typography, font sizes, spacing and layout. Only colors/backgrounds should change. Use Sora for elegant headings and Plus Jakarta Sans for clean body text, consistently across both themes.

Dark theme: #07111F, #0B1628, #101C2E, footer #050A12, gold #D4AF37, teal #14B8A6, white text.

Light theme: #F7F8FA, #FFFFFF, #EEF2F6, navy text, gold and teal accents.

Home: premium hero with “Engineering Ideas Into Digital Products.”, CTA buttons and modern technology visual.

About: company introduction, vision, mission, values and engineering approach.

Services: Software Development, Full-Stack Development, Enterprise Solutions, AI & Automation, Database & Architecture, Maintenance.

Product Showcase: premium product/project cards with visuals, descriptions and technologies. Do not use fake clients, testimonials or statistics.

Create a connected Product Showcase + Contact section, with products on one side and a professional contact form on the other.

Contact form: Name, Email, Company, Project Type, Message and Submit button.

Add a floating WhatsApp button fixed at the bottom-right corner on every section. It must remain visible while scrolling, have a clean WhatsApp icon, subtle hover animation, tooltip such as “Chat with us”, and open the company's WhatsApp chat link in a new tab when clicked. Keep the WhatsApp number as an easily configurable variable/placeholder; do not invent a number.

Footer: golden logo, navigation, services, contact/social links and copyright.

Make everything responsive for desktop, tablet and mobile. Use smooth scrolling, subtle animations, hover states, accessible contrast, clean spacing and a premium software-company aesthetic. Keep the entire website static, single-page and client-ready.
